# McDobalds menu photos

Add one clear photo supplied by the restaurant for each menu item. Save each image as a WebP file in this folder using the dish name in lowercase, with spaces and punctuation changed to hyphens.

Examples:
- `Tapsilog` → `tapsilog.webp`
- `Chicken Feet Adobo` → `chicken-feet-adobo.webp`
- `Fried Chicken · Half` → `fried-chicken-half.webp`
- `McDobald’s Pika Pika` → `mcdobald-s-pika-pika.webp`

Each menu card is already wired to its own matching filename and uses that photo as its background. Keep the original dish recognizable; use a sharp, well-lit image with no text or menu-board graphics. The site falls back to a dark diner-color background until the matching photo is added.
